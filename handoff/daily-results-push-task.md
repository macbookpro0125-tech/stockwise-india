Daily results push for Jocular Insights (NSE stock research site jocularinsights.in; code in ~/Projects/stockwise-india, branch screeners-home). Read the last 20 lines of handoff/LOG.md first. Why: Search Console shows company results pages are the pages that reach Google's first page, so each day's new results pages are pushed while people search for them.

1. Run `node scripts/results-day.mjs` in the repo. It reads the live /results page and handoff/indexing-state.json and prints JSON: `google` (up to 10 URLs not yet requested), `bing` (up to 100 not yet submitted), `short` (a candidate company or null). If google and bing are both empty (between results seasons), write one line to handoff/LOG.md saying nothing new, commit it, and stop.

2. Google (built-in browser, the jocularinsights@gmail.com Search Console, already signed in; never type a password; if a sign-in page appears, stop this step and say so): open https://search.google.com/search-console?resource_id=https%3A%2F%2Fjocularinsights.in%2F. For each URL in `google`: click the search icon at the top, select all, type the URL, Enter, wait ~10 s; if it says "URL is on Google" skip it; otherwise click REQUEST INDEXING and wait 20–40 s for "Indexing requested", then Dismiss and wait 2 s before the next (clicking too soon re-requests the previous page). Stop at "Quota Exceeded" (about 10 per rolling 24 h). Record the ones accepted: `node scripts/results-day.mjs --mark google URL…`.

3. Bing (built-in browser): open https://www.bing.com/webmasters/submiturl?siteUrl=https://jocularinsights.in/, click "Submit URLs", click into the box and type the `bing` URLs one per line (check the box's line count with JavaScript before submitting), click Submit, confirm they appear as submitted today. Record: `node scripts/results-day.mjs --mark bing URL…`.

4. One Short, if `short` is not null: run `node scripts/short-from-results.mjs SYMBOL` (2–4 minutes; it reads the figures from the live results page and writes replica/launch/shorts/auto-<symbol>.mp4 and .txt with the title and description). Look at a frame (ffmpeg -ss 10 … -frames:v 1) and check every figure against the live results page; if anything disagrees, don't upload and say so. Then, with Claude in Chrome (the owner's Chrome, Jocular profile; if Chrome isn't connected, skip the upload and say so): copy the mp4 into ~/Projects/files/shorts-upload/ (uploads must come from the session folder; delete the copy afterwards), open YouTube Studio for the Jocular Insights channel, Upload videos, upload via the hidden file input, paste the title and description from the .txt, mark "No, it's not made for kids", Next ×3, and under Visibility choose Schedule for TODAY at 3:30 PM in the default time zone (GMT+3, which is 6 pm IST) — or tomorrow 3:30 PM if that time has passed. Then add music: Content → Shorts → the new Short → Editor → Get started → Audio → filter "Attribution not required" and mood Bright or Uplifting → pick a track not used before (used so far: Corporation Motivation, Beat Your Competition, Above and Beyond — keep the list in the log line) → Add → Save → tick the acknowledgement → Confirm. If a credit dialog appears anyway, add the credit to the description. Record: `node scripts/results-day.mjs --mark short SYMBOL`.

5. Add one line to handoff/LOG.md (date; how many Google requests accepted; Bing count; the Short's company, YouTube link, schedule time and music track) and commit handoff/LOG.md and handoff/indexing-state.json only (git fetch first; other tools edit this repo; never push; end the commit message with "Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>").

6. Finish with a 3-line plain summary for the owner (simple English, he reads on his phone). Never invent figures; no buy/sell/target words (SEBI); never publish anything but the one Short; never change account settings.
